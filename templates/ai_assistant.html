Gemini API Key Required

To use the AI Assistant, you need to configure your Gemini API key.

  1. Visit Google AI Studio: https://aistudio.google.com/
  2. Create a free Gemini API key.
  3. Copy .env.example to .env in the project folder.
  4. Add your key: GEMINI_API_KEY=your-key-here
  5. Add from dotenv import load_dotenv; load_dotenv() at the top of app.py
  6. Restart the Flask app.
The API key is stored in .env which is excluded from Git via .gitignore. It is NEVER exposed in HTML or JavaScript.
